# 🛒 ONLINE SHOPPING SYSTEM in Advanced C

## 📌 Introduction
The **Online Shopping System** is a **C-based console application** that allows users to browse, select, modify, and purchase items across various categories. The system efficiently manages product listings, cart operations, and billing functionalities.

## ⚡ Key Features
✔️ **Product Categories** – Electronics, Books, Shoes, Fashion, Appliances, Furniture, Groceries, Beauty, Pharmacy, and Sports.
✔️ **Cart Management** – Add, remove, and modify item quantities in the cart.
✔️ **Billing System** – Generates a total bill based on selected items.
✔️ **User-Friendly Interface** – Simple and interactive menu-driven system.

## 📋 Functionalities
🔹 **Display Available Items** – Browse various product categories.
🔹 **Add Items to Cart** – Select and add products with quantity options.
🔹 **Remove Items** – Delete items from the cart.
🔹 **Modify Cart** – Change the quantity of selected items.
🔹 **Generate Bill** – Calculate total cost and display a final invoice.
